You set values in `deploy/docker/.env`. Docker Compose substitutes them into `docker-compose.yml`, which passes them to each container. A change needs `docker compose up -d` (and a rebuild of `caddy` for values baked into the web build).

"Secret" means a value to keep private. `scripts/gen-secrets.sh` generates every secret that is empty in `.env` and never overwrites a value that is set.

## `.env` keys

### Hostnames and TLS

| Name | Required | Default | Example | What it does / what breaks if wrong |
|---|---|---|---|---|
| `APP_HOST` | yes | `maple.example.com` | `maple.acme.com` | Dashboard hostname. Also the Keycloak redirect URI (`https://APP_HOST/sign-in`) and `MAPLE_APP_BASE_URL`. Wrong DNS: Caddy cannot get a certificate. Changed later: rerun `bootstrap.sh` |
| `API_HOST` | yes | `api.maple.example.com` | `api.maple.acme.com` | API hostname, baked into the web build (rebuild `caddy` after changing) |
| `SYNC_HOST` | yes | `sync.maple.example.com` | | Live-sync hostname, baked into the web build. Wrong: the dashboard loads but never updates live |
| `AUTH_HOST` | yes | `auth.maple.example.com` | | Keycloak hostname (`KC_HOSTNAME`) and the browser-facing OIDC URLs. Wrong: sign-in redirects fail |
| `INGEST_HOST` | yes | `ingest.maple.example.com` | | OTLP hostname. Baked into the web build and shown in setup instructions |
| `STATUS_HOST` | yes | `status.maple.example.com` | | Public status page hostname (new). Baked into the web build as `PUBLIC_STATUS_URL`. Empty: Caddy fails to start and no status link is shown |
| `ACME_EMAIL` | yes | `it@example.com` | | Contact for Let's Encrypt |

### Email

| Name | Required | Default | Example | What it does / what breaks if wrong |
|---|---|---|---|---|
| `SMTP_URL` | for email | empty | `smtps://user:pass@smtp.acme.com:465` | Secret. `smtps://` is TLS (port 465 default), `smtp://` is STARTTLS (587 default). Used by Maple's mail bridge and parsed by `bootstrap.sh` for Keycloak's SMTP. Empty: no email at all |
| `SMTP_INSECURE` | no | `0` | `1` | `1` allows a plain SMTP server with no TLS (an internal relay) |
| `EMAIL_FROM` | yes | `maple@example.com` | `Maple <maple@acme.com>` | Sender for Maple and Keycloak mail. A domain your SMTP provider does not allow gets rejected. A display name is allowed |

### Web build and ports

| Name | Required | Default | Example | What it does |
|---|---|---|---|---|
| `MAPLE_WEB_INGEST_KEY` | no | empty | `maple_pk_...` | An organization's **public** ingest key so the dashboard reports its own performance. Baked into the web build. Rebuild `caddy` after changing. Empty: harmless `Missing ingest key` warnings in `ingest` |
| `OTLP_HTTP_LOCAL_PORT` | no | `4318` | | Loopback port for OTLP/HTTP (`127.0.0.1:PORT` to `ingest:3474`) |
| `OTLP_GRPC_LOCAL_PORT` | no | `4317` | | Loopback port for OTLP/gRPC |
| `WEB_PORT`, `API_PORT`, `SYNC_PORT`, `AUTH_PORT`, `INGEST_PORT` | no | `8780`, `8701`, `8705`, `8080`, `3474` | | Loopback ports, used **only** with `docker-compose.host-proxy.yml` |

### Secrets (generated by `gen-secrets.sh`)

| Name | Required | Default | What it does / what breaks if wrong |
|---|---|---|---|
| `POSTGRES_PASSWORD` | yes | generated | Password of the `maple` Postgres user. It is stored in the database volume on first start, so changing `.env` alone breaks every service |
| `CLICKHOUSE_ADMIN_PASSWORD` | yes | generated | ClickHouse `admin` user. Used by `maple` to create one database and user per organization. Same caveat as Postgres |
| `KEYCLOAK_ADMIN_USER` | yes | `admin` | Keycloak's bootstrap admin name (first start only; `bootstrap.sh` signs in with it) |
| `KEYCLOAK_ADMIN_PASSWORD` | yes | generated | That admin's password. Keycloak ignores it once an admin exists |
| `MAPLE_ROOT_PASSWORD` | yes | generated | Break-glass IT login. Fallback signing key for session tokens when `MAPLE_SESSION_SECRET` is unset |
| `MAPLE_INGEST_KEY_ENCRYPTION_KEY` | yes | generated (base64, 32 bytes) | **Never change after first start.** Encrypts ingest keys and other stored secrets. A change makes them unreadable |
| `MAPLE_INGEST_KEY_LOOKUP_HMAC_KEY` | yes | generated | **Never change after first start.** Lookup hash of ingest keys. A change makes every existing key return `401` |
| `MAPLE_SHARE_TOKEN_HMAC_KEY` | yes | generated | Signs share links. A change invalidates existing links |
| `INTERNAL_SERVICE_TOKEN` | yes | generated | Bearer between Maple's own Workers |
| `SANDBOX_INTERNAL_SERVICE_TOKEN` | yes | generated | Token for the PR-review sandbox bridge (the sandbox itself is unavailable here) |
| `ELECTRIC_SECRET` | yes | generated | Shared by `electric` and `maple`. Electric accepts shape requests only with it |
| `SD_INTERNAL_TOKEN` | yes | generated | Bearer for the scraper's `/api/internal/*` calls. Must be the same in `maple` and `scraper` |
| `MAPLE_SESSION_SECRET` | recommended | generated | HMAC key for session tokens. Unset: falls back to `MAPLE_ROOT_PASSWORD`. A change signs everyone out |
| `MAPLE_OIDC_ADMIN_CLIENT_SECRET` | for IT admin features | generated | Secret of the Keycloak `maple-admin` client. `bootstrap.sh` sets the client to this value |

### Sign-in and bootstrap

| Name | Required | Default | What it does |
|---|---|---|---|
| `MAPLE_OIDC_SESSION_TTL_SECONDS` | no | `600` | Lifetime of one Maple session token. Clamped to 120-3600. Also the longest a removed user's token keeps working |
| `MAPLE_OIDC_SESSION_MAX_LIFETIME_SECONDS` | no | `43200` | Absolute length of one sign-in before a new login is needed. Clamped to 3600-604800 |
| `KEYCLOAK_CLOSE_ACCOUNT_CONSOLE` | no | `1` | Read by `bootstrap.sh`. `1` removes `manage-account` from users' default roles so they cannot open Keycloak's account console. `0` restores it |
| `REALM_DISPLAY_NAME` | no | `Maple` | Read by `bootstrap.sh`. The company or organization name shown on the Keycloak sign-in pages (tab title) and inside the body of Keycloak emails. Keycloak does not pass a name to email subjects, so subjects stay generic ("Confirm your email"). Re-run `./scripts/bootstrap.sh` after changing it. |
| `CURL_OPTS` | no | empty | Read by `bootstrap.sh` and `smoke-test.sh`. `-k` for the local CA on `*.localhost` |

## Scraper environment

From `apps/scraper/src/Env.ts`. Only the first three are set by compose.

| Name | Default | Set in compose | What it does |
|---|---|---|---|
| `MAPLE_API_URL` | `http://127.0.0.1:3472` | `http://maple:8701` | API base URL. The default does not work in a container, so it must be set |
| `SD_INTERNAL_TOKEN` | `maple-sd-dev-token` | `${SD_INTERNAL_TOKEN}` | Bearer for `/api/internal/*`. The built-in default is a public dev value: never run without setting it |

| `SCRAPER_CONCURRENCY` | `10` | | Max concurrent scrapes (1-10000) |
| `SCRAPER_RECONCILE_INTERVAL_SECONDS` | `60` | | How often the target list is refreshed |
| `SCRAPER_OTLP_MAX_DATA_POINTS` | `10000` | | Max data points per OTLP POST |

## Maple backend variables

From `packages/backend/src/platform/Env.ts`. Only the ones that matter for this deployment.

### Auth and sessions

| Name | Required | Default | Example | What it does / what breaks if wrong |
|---|---|---|---|---|
| `MAPLE_AUTH_MODE` | no | `self_hosted` | | Leave at the default. Workers verify Maple's own session tokens |
| `MAPLE_ROOT_PASSWORD` | yes | none | | Root login. Signing-key fallback |
| `MAPLE_SESSION_SECRET` | no | falls back to `MAPLE_ROOT_PASSWORD` | | HMAC key for session tokens. Every Worker that verifies sessions (api, electric-sync) must see the same value |
| `MAPLE_OIDC_AUTHORIZE_URL` | for SSO | none | `https://auth.acme.com/realms/maple/protocol/openid-connect/auth` | Browser-facing authorize endpoint. Compose sets it from `AUTH_HOST` |
| `MAPLE_OIDC_TOKEN_URL` | for SSO | none | `http://keycloak:8080/realms/maple/protocol/openid-connect/token` | Server-to-server token endpoint (private network). SSO is on only when this **and** `MAPLE_OIDC_CLIENT_ID` are set |
| `MAPLE_OIDC_CLIENT_ID` | for SSO | none | `maple-web` | The public client's id |
| `MAPLE_OIDC_ISSUER` | recommended | none | `https://auth.acme.com/realms/maple` | The `iss` every sign-in must carry. Unset: `iss` is not checked. Wrong: all SSO sign-ins are rejected |
| `MAPLE_OIDC_LOGOUT_URL` | recommended | none | `http://keycloak:8080/realms/maple/protocol/openid-connect/logout` | End-session endpoint. Unset: logout only revokes Maple's session and the IdP session survives |
| `MAPLE_OIDC_ACCOUNT_URL` | no | none | `https://auth.acme.com/realms/maple/account` | Link to the IdP account console (shown to IT) |
| `MAPLE_OIDC_ROOT_ROLE` | no | `maple-root` | | IdP role that grants `root` |
| `MAPLE_OIDC_SESSION_TTL_SECONDS` | no | `600` | | Clamped to 120-3600 |
| `MAPLE_OIDC_SESSION_MAX_LIFETIME_SECONDS` | no | `43200` | | Clamped to 3600-604800 |
| `MAPLE_OIDC_ADMIN_URL` | for IT admin features | none | `http://keycloak:8080/admin/realms/maple` | Keycloak Admin REST base. Needs the secret too |
| `MAPLE_OIDC_ADMIN_CLIENT_ID` | no | `maple-admin` | | The confidential service-account client |
| `MAPLE_OIDC_ADMIN_CLIENT_SECRET` | for IT admin features | none | | Its secret (see [Security](/docs/self-hosting/multi-tenant/security#the-maple-admin-service-account)) |
